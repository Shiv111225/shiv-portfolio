# shiv-portfolio
3D portfolio website — Shiv Shrivastav, Creative Technologist (AR/VR & AI).
Panther & goo theme built with three.js; sounds synthesised in the browser.

Currently live at https://shiv-shrivastav.netlify.app

## Run locally
```bash
python3 -m http.server 8000
```
Then open http://localhost:8000.

Static site, no build step: publish directory is the repo root.
